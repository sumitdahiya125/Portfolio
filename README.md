# sumitdahiya125.github.io

Personal portfolio site — plain HTML / CSS / JS, no build step.
Deployed automatically by GitHub Pages from the `main` branch.

**Live:** https://sumitdahiya125.github.io

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Edit

- `index.html` — content
- `style.css` — styling (dark theme, CSS variables at the top)
- `script.js` — small scroll-reveal & footer year
